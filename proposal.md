## **What I'm Building**
A smart travel‑planning web application that helps users create trips, build itineraries, check weather, choose outfits, find flights, and convert currency.

## **Who It's For / Why I Chose This**
I love traveling and planning trips, and I wanted to build a tool I would genuinely use. This app solves a real need: organizing travel details in one place while automatically pulling helpful information like weather, outfit suggestions, flight options, and currency conversion.

## **Core Features**

- **Trip creation** — users add destinations, dates, and notes.
- **Weather + outfit suggestions** — uses the OpenWeather API to show forecasts and recommend outfits for each day.
- **Flight search** — integrates AviationStack to display flight options for the destination.
- **Currency conversion** — uses ExchangeRate API to convert budgets into local currency.
- **Itinerary builder** — users can add daily activities, restaurants, and plans, saved in localStorage.

## **What I Don’t Know Yet**

- How to structure API calls efficiently and handle errors (e.g., missing data, rate limits).
- How to combine multiple APIs into one smooth user flow without slowing the app.
- How to design a clean, responsive UI that works well on both desktop and mobile.
- How to store itinerary data in localStorage in a way that’s easy to update and retrieve.
- How to manage date‑based weather forecasts for multi‑day trips.
