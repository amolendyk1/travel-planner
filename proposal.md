## **What I'm Building**
A smart, all‑in‑one travel‑planning web application that helps users create trips, build itineraries, check weather, get outfit recommendations, explore maps, manage budgets, and convert currency — all in one clean, responsive interface.

## **Who It's For / Why I Chose This**
I love traveling and planning trips, and I wanted to build a tool I would genuinely use. Travelers often jump between multiple apps for weather, packing, flights, budgeting, and itinerary notes. This project solves that problem by centralizing everything into one seamless experience. It’s designed for anyone who wants a simple, aesthetic, and intelligent way to organize their travel plans.

## **Core Features**

- **Trip creation** - Users add destinations, dates, trip photos, and notes. Each trip becomes a personalized dashboard.
- **Weather + outfit suggestions** -  Uses the OpenWeather API to show daily forecasts and generate outfit recommendations based on temperature, rain, and wind.
- **Currency conversion** - Converts budgets into local currency using ExchangeRate API and displays daily spending estimates.
- **Itinerary builder** - Users add activities, restaurants, and plans for each day. Data is stored locally for now, with future support for cloud sync.
- **Packing checklist** - Auto‑generated packing suggestions based on weather and trip type (beach, city, adventure).
- **Map integration** - Displays attractions, restaurants, and itinerary locations using Leaflet or Google Maps.
