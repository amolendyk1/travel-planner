## **What I'm Building**
TravelFlow is a lightweight travel-planning web app that helps users shape a trip in one place which focuses on trip setup, travel insights, and itinerary planning through a simple multi-page experience.

## **Who It's For / Why I Chose This**
I chose this project because I wanted to build something useful for real trip planning without making users jump between several apps. It is designed for casual travelers who want a clean way to organize a destination, budget, weather-related prep, and daily plans in one experience.

## **Core Features**

- **Trip setup** - Users enter a destination, travel dates, budget, and currency. These details are shown in a trip overview and planning flow.
- **Travel insights** - The app displays weather-based guidance, packing suggestions, budget planning, and practical travel information for the selected destination.
- **Itinerary builder** - Users can create a day-by-day itinerary with editable activity entries saved in the browser.
- **Destination exploration** - The app includes location-based suggestions for landmarks, restaurants, hotels, and transport ideas for supported destinations.
- **Local persistence** - Trip details and itinerary data are stored using browser localStorage so the plan remains available after refresh.
- **Simple responsive UI** - The app uses a clean, step-based layout designed for desktop and mobile viewing.
